노래 악보 만들기

mp3·wav를 넣으면 보컬을 분리해 악보와 가사를 PDF로 만들어요

설정

  1. 음원 넣기 — mp3·wav·flac·m4a 파일을 왼쪽 칸에 끌어다 놓아요. 영어 노래는 가사 언어를 「자동 감지」나 「영어」로 고르면 더 정확해요.
  2. 분석 기다리기 — 보컬 분리 → 가사 → 멜로디 → 템포·코드 순서로 진행돼요. 처음 한 번은 분석 모델(약 2GB)을 받느라 더 걸려요.
  3. 악보 고르기 — 멜로디 · 피아노(쉬운/원곡) · 기타 TAB · 기타 코드 중에서 골라요.
  4. 재생하며 확인 — ▶ 또는 스페이스 키. 지금 부르는 음표와 가사가 빨간색으로 표시돼요.
  5. 가사 고치기 — 음표나 가사를 누르면 바꾸기 · 지우기 · 끼워 넣기 · 당기기를 할 수 있어요.
  6. 보정 — 템포가 두 배/절반이면 「½배·2배」, 마디가 밀리면 「첫 박 위치」, 키가 높으면 「조옮김」.
  7. 저장 — PDF · MusicXML · MIDI, 분리된 보컬·반주 wav를 저장할 수 있어요.
